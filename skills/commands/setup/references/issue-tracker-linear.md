# Issue tracker: Linear

Issues and specs for this repo live in Linear. Use the configured Linear MCP for all operations.

## Conventions

- **Create an issue**: create it in the configured Linear team and project with the required title, description, labels, and relationships.
- **Read an issue**: fetch the issue, including its description, status, labels, parent, dependencies, and comments.
- **List issues**: query issues using the appropriate team, project, status, and label filters.
- **Comment on an issue**: add a comment to the issue.
- **Apply / remove labels**: update the issue labels.
- **Update status**: move the issue to the appropriate workflow status.
- **Close**: move the issue to the team's completed or canceled status as appropriate.

Use the team and project configured for this repo. Do not guess them when they cannot be determined from existing project context.

## When a skill says "publish to the issue tracker"

Create a Linear issue in the configured team and project.

## When a skill says "fetch the relevant ticket"

Fetch the referenced Linear issue, including its description, labels, relationships, and comments.
